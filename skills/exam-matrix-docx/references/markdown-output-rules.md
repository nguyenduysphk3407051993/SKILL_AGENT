# Markdown output rules

- Toàn bộ output đặt trong code block markdown.
- Loại 1: A/B/C/D mỗi phương án một dòng.
- Loại 2: a/b/c/d mỗi ý một dòng; có thể kiểu bảng hoặc không bảng.
- Loại 3: đáp án dạng bảng ký tự tối đa 4 ô.
- Loại 4: tự luận có lời giải chi tiết.
- Công thức toán/hóa dùng LaTeX chuẩn: inline `$...$`, display `$$...$$`.
